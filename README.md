## 💡 工程哲学 (Engineering Philosophy)

> **"Make it work, make it simple, make it maintainable."**

1. **规划优先，简洁直接**：大需求先设计验证再动手，小任务敏捷修复，杜绝无意义的过度设计。
2. **轻量与单体效能**：在业务体量匹配时，优先深挖单体架构与进程内通信（如 SQLite WAL），避免引入多余网络与中间件故障点。
3. **交付即代码**：规范的 Git Flow、常规提交（Conventional Commits）与自动化脚手架，保证长期代码可维护性。
